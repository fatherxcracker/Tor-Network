## What will be here
This folder will contain a list of commands in order to guide the user to test the middle next relay. 
These commands will be primarily used when the user has finished configuring it as they will need Nyx to monitor the relay, view bandwidth usage, and observe network activity.
There will also be commands/scripts detailing how to install the Tor Browser and set up the VPS if any user wishes to recreate this setup.
